# LEARNOS X: Agentic AI Orchestrator

## 8 Specialized Sub-Agents
1. **Career Agent**: Parses natural language goals, extracts target roles, matches company skill fingerprints.
2. **Learning Agent**: Manages the Learner Digital Twin and Adaptive Learning DNA.
3. **Assessment Agent**: Selects diagnostic assessment items and evaluates attempts.
4. **Resource Agent**: Ranks learning resources by semantic fit and learning style preferences.
5. **Path Planner Agent**: Performs topological prerequisite sorting and builds weekly milestones.
6. **Tutor Agent**: Executes Socratic tutoring dialogue and concept explanations.
7. **Evidence Agent**: Aggregates multi-source evidence into verified skill confidence.
8. **Portfolio Agent**: Synthesizes verified evidence into clean portfolio showcases.

Every agent action and tool call is logged in `AgentExecution`.
